# 🚀 Meus Estudos de Node.js & Express

Bem-vindo(a) ao meu repositório de estudos sobre **Node.js**! Este espaço foi criado para registrar, documentar e organizar todo o conteúdo, códigos, exercícios e projetos práticos que venho desenvolvendo à medida que aprofundo meus conhecimentos nessa tecnologia.

---

## 📌 Sobre o Repositório

O objetivo principal deste repositório é servir como um diário de aprendizado e consulta contínua sobre desenvolvimento **backend** com Node.js. Aqui você encontrará:

- **Anotações e Conceitos:** Explicações teóricas sobre o ecossistema Node.js, arquitetura baseada em eventos (*Event Loop*), assincronismo, entre outros.
- **Códigos Práticos:** Exemplos de implementação de APIs, manipulação de arquivos, integração com banco de dados e rotas.
- **Projetos de Fixação:** Pequenas aplicações e microsserviços desenvolvidos para consolidar o aprendizado na prática.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

Neste repositório, utilizo as seguintes tecnologias fundamentais:

| Tecnologia / Ferramenta | Descrição |
| :--- | :--- |
| **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)** | Linguagem principal utilizada nos scripts e desenvolvimento backend. |
| **[Node.js](https://nodejs.org/)** | Ambiente de execução JavaScript no lado do servidor. |
| **[Express.js](https://expressjs.com/pt-br/)** | Framework web rápido e minimalista para criação de rotas, middlewares e APIs RESTful. |
| **NPM / YARN** | Gerenciador de pacotes para dependências e bibliotecas do ecossistema. |

## 🚀 Como Executar os Exemplos Localmente

Se você deseja clonar e testar os arquivos deste repositório na sua máquina, siga os passos abaixo:

### Pré-requisitos
- **[Node.js](https://nodejs.org/)** instalado (versão LTS recomendada).
- **Git** instalado.

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Guilherme-Hirohara/Node.js
   ```

2. **Acesse a pasta do projeto desejado:**
   ```bash
   cd Node.js/escolha-o-conteudo
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Execute o servidor/aplicação:**
   ```bash
   npm start
   ou
   node index.js
   ```
